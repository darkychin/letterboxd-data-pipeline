# Transformation Note

## Columns Ignored

Name such as actor's name, movie's name or any related columns in the similar sense will be ignored during transformation, because it lacks purpose to do so and does not worth the effort.

This is supported with the following exploration:
- [bronze - actors column characters](../exploration/20260127-bronze-actors-column-chars.ipynb)
- [bronze - crew column characters](../exploration/20260127-bronze-crew-column-chars.ipynb)
- [bronze - actors possible NAs](../exploration/20260129-bronze-actors-nas.ipynb)

Ignored transformation will includes
- special characters removal
- possible NA removal
